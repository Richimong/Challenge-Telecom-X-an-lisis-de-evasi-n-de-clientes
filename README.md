# Challenge-Telecom-X-an-lisis-de-evasión-de-clientes

El objetivo del ejercicio era analizar y comprender las variables que explicaran la decisión de terminar el contrato de servicio por parte de los clientes, contando con información personal de los clientes como género, si tiene pareja o no, si tiene dependientes, los servicios contratados por el cliente, el tipo de contrato, forma de pago, método de comunicación del pago así como el costo mensual y costo total de cada cliente.

Como toda base de datos se exploró para generar consistencia y tener una base sólida que permitiera un correcto análisis evitando sesgos en las conclusiones finales.

En este repositorio se encontrará el archivo .json con la base original de los datos así como el arhcivo .ipynb con el tratamiendo de la base, los análisis generados.

# Conclusiones generales

* Existen servicios que no son de interés para el cliente como es el servicio de telefonía, hoy en día utilizamos más el celular por lo que el telefono en casa podría estar obsoleto, sin embargo, es un servicio que está generando un costo hacia el cliente.

* Los tiempos de contratación, el mayor impacto económico se observa en aquellos servicios que se contrataron por 2 años, se propone una revisión a los tiempos de contratación y ajustarlo a las condiciones actuales del mercado.

* Relación calidad-precio en los servicios de internet, específicamente aquellos que contrataron fibra óptica, una encuesta de satisfacción daría un mejor entendimiento sobre la percepción del servicio.
